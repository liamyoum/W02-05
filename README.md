# Krafton Jungle 12th Week02 - Week05
## Data Structure and Algorithm

### Week2
크래프톤 정글 12기 2주차 ~ 5주차 동안 학습한 자료구조 및 알고리즘 문제 풀이를 정리한 레포지토리입니다.
주차별 학습 주제를 기준으로 폴더를 분리했고, 각 주차마다 기초 문제와 난이도별 문제 풀이를 정리했습니다.

## Repository Structure

각 주차 폴더는 아래와 같은 구조로 구성되어 있습니다.

- `basic/`
  - 해당 주차 알고리즘의 기초 개념 및 기본 문제
- `problem-solving/`
  - 난이도별 문제 풀이
  - 하 / 중 / 상 / Extra
